# Документация проекта: Анализ репозиториев кода

## Описание проекта

Это проект агента для автоматического анализа репозиториев кода. Агент использует ReAct loop (Reasoning + Action) для выполнения задач по изучению структуры проекта, анализу кода и генерации документации. Проект решает задачу автоматизации анализа программного кода без необходимости ручного изучения каждого файла.

## Структура проекта

```
.
├── agent.py           # Основной класс агента с ReAct loop и обработкой потоков
├── tools.py           # Реализация инструментов: чтение файлов, поиск, запись
├── analyze_tool.py    # Инструмент для AST-анализа Python-файлов
├── mermaid_tool.py    # Инструмент для генерации Mermaid-диаграмм
├── main.py            # Точка входа, инициализация агента
├── config.yaml        # Конфигурация: настройки LLM, пути, лимиты
├── prompts/           # Промпты для системы и задачи
│   ├── system.txt     # Промпт системы (правила поведения агента)
│   └── task.txt       # Промпт задачи (что агент должен сделать)
├── docs/             # Выходная директория для документации
├── requirements.txt   # Зависимости проекта
└── README.md         # Документация проекта
```

### Описание файлов

- **agent.py** — основной модуль, содержащий базовый класс `Tool` и класс `Agent` с методом `think_and_act`, который реализует цикл размышления и действий. Также содержит функции загрузки конфигурации и промптов.

- **tools.py** — реализация четырёх инструментов: `ReadFileTool` (чтение файлов), `ListDirTool` (перечисление директорий), `GrepTool` (поиск по паттернам), `WriteFileTool` (запись файлов). Все инструменты наследуются от базового класса `Tool`.

- **analyze_tool.py** — инструмент `AnalyzePythonTool`, который использует модуль `ast` для анализа структуры Python-файлов без чтения всего содержимого. Извлекает информацию о классах, функциях, импортах и док-строках.

- **mermaid_tool.py** — инструмент `GenerateMermaidTool`, который генерирует Mermaid-диаграммы с автоматической валидацией и коррекцией синтаксиса.

- **main.py** — точка входа приложения. Инициализирует агента с заданными инструментами, загружает конфигурацию из `config.yaml` и промпты из директории `prompts`, запускает цикл обработки задачи.

- **config.yaml** — файл конфигурации с настройками LLM API (URL, модель, температура, токены), параметрами агента (максимальное число шагов, допустимые сбои парсинга), путями к файлам и правилами безопасности при записи.

- **prompts/system.txt** — промпт системы, определяющий правила поведения агента, формат ответов и ограничения.

- **prompts/task.txt** — промпт задачи, задающий конкретное действие для выполнения (например, "создай документацию для репозитория").

- **requirements.txt** — список внешних зависимостей проекта.

## Архитектура

### Основные классы

- **Tool** — базовый класс для всех инструментов. Содержит атрибуты `name` и `description`, а также метод `execute()` для выполнения действия.

- **Agent** — основной класс агента. Содержит конфигурацию и список инструментов. Метод `get_system_prompt()` возвращает промпт системы, а `think_and_act(task)` реализует цикл размышления и действий.

- **ReadFileTool** — инструмент для чтения содержимого файлов.

- **ListDirTool** — инструмент для перечисления содержимого директорий.

- **GrepTool** — инструмент для поиска паттернов в Python-файлах.

- **WriteFileTool** — инструмент для записи файлов с поддержкой безопасной записи (блокировка чувствительных директорий).

- **AnalyzePythonTool** — инструмент для AST-анализа Python-файлов.

- **GenerateMermaidTool** — инструмент для генерации Mermaid-диаграмм.

## Зависимости

## Быстрый старт

### Установка

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что Atomic Chat запущен на `http://localhost:1337/v1`.

### Конфигурация

Редактируйте файл `config.yaml`:

- `llm.api_url` — URL вашего Atomic Chat API.
- `llm.model` — модель для использования.
- `llm.temperature` — температура генерации (0.1 для детерминированных ответов).
- `llm.max_tokens` — максимальное число токенов в ответе.
- `llm.stream` — включить потоковую передачу ответа.
- `llm.show_tokens` — показывать печатающиеся токены в консоли.
- `agent.max_steps` — максимальное число шагов в цикле.
- `agent.max_parse_failures` — допустимое число сбоев парсинга.
- `paths.system_prompt` — путь к промпту системы.
- `paths.task_prompt` — путь к промпту задачи.
- `paths.output_dir` — директория для вывода документации.
- `paths.log_file` — файл для отладочных логов.
- `write_safety.blocked_patterns` — директории, в которые агент не будет писать файлы.

### Запуск

Запустите приложение:

```bash
python main.py
```

Агент начнёт выполнение задачи, указанной в `prompts/task.txt`. В консоли вы увидите:

- Печатающиеся токены в реальном времени.
- Размышления агента и принятые действия.
- Результат выполнения задачи.

При нажатии Ctrl+C агент выполнит graceful остановку.
